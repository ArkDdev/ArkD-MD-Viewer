# Итерация 3.1 — Display panel + локальные шрифты + закрытие скобок

## Что нужно сделать

1. **Шрифты должны быть на месте** — в `public/fonts/` 12 файлов `.woff2`. Если ты уже скачал через `curl.exe` — всё ок.

2. Распакуй архив поверх проекта. Семь файлов:
   - `src/components/chrome/DisplayModal.tsx` — реальные контролы вместо заглушки
   - `src/components/editor/Editor.tsx` — динамический font-size, wrap, closeBrackets
   - `src/components/viewer/Renderer.tsx` — применение всех display prefs
   - `src/store/uiStore.ts` — расширен под новые настройки
   - `src/styles/globals.css` — `@font-face` декларации, line-height через CSS-переменную
   - `tailwind.config.ts` — три варианта ширины
   - `package.json` — добавлена зависимость `@codemirror/autocomplete`

3. **Запусти `npm install`** — подтянется `@codemirror/autocomplete`.

4. Перезапусти dev-сервер `npm run tauri:dev`. Шрифты загружаются как статические файлы из `public/`, никакой компиляции не требует.

## Что добавлено

### Display panel — реальные настройки (вместо заглушки)

Modal, открываемый по иконке-слайдеру в правом верхнем углу. Содержит два раздела:

**Документ:**
- **Шрифт** — Serif / Sans / Mono. Каждая кнопка отрисована своим шрифтом (визуальный preview)
- **Размер** — A12 / A14 / A16 / A18 px (буквы разного размера)
- **Высота строки** — Плотно (1.5) / Обычно (1.7) / Просторно (1.9)
- **Ширина** — Узкая (720) / Средняя (860) / Широкая (1040) / По окну

**Редактор:**
- **Размер шрифта** — 12 / 14 / 16 / 18 px
- **Перенос строк** — toggle on/off

Внизу — кнопка "Сбросить к настройкам по умолчанию" + "Готово".

Все настройки применяются **в реальном времени** — поменял шрифт, сразу видно эффект. Persist через тот же `arkd-ui` localStorage ключ.

### Локальные шрифты

В `globals.css` добавлены `@font-face` декларации для всех 12 файлов в `public/fonts/`. Используется техника **subset splitting** через `unicode-range`:

- Когда документ содержит только латиницу, браузер загружает только `*-latin-*.woff2`
- Когда появляется кириллица — лениво подгружается `*-cyrillic-*.woff2`

Это значит: если ты читаешь английский markdown, не загрузятся файлы кириллицы. И наоборот. Total бандл ~200 КБ, но в runtime обычно используется 50-100 КБ.

`font-display: swap` — пока шрифт грузится, текст показывается fallback'ом (Charter/Georgia для serif, Segoe UI для sans). Никакой "невидимый текст" не показывается.

### closeBrackets в редакторе

Включен extension `@codemirror/autocomplete/closeBrackets`. При наборе:

- `(` → автоматически вставляется `()`, курсор внутри
- `[` → `[]`
- `{` → `{}`
- `"` → `""`
- `'` → `''`

Smart skip: если набираешь `)` в позиции, где уже есть `)` — курсор просто проходит через неё, не дублируя. То есть `(hello)` через `(`, `h`...`o`, `)` — корректно.

Backspace на пустых парных скобках удаляет обе сразу.

**НЕ** включены автозамены для `*`, `_`, `` ` `` — они слишком часто используются в markdown и автодополнение мешает.

Стоимость: `@codemirror/autocomplete` ~30 КБ в bundle, после tree-shaking ~10-15 КБ (используем только closeBrackets).

## Архитектурные заметки

### Compartments в CodeMirror

Я использовал три Compartment'а в Editor:
- `highlightCompartment` для смены light/dark подсветки
- `themeCompartment` для смены font-size
- `wrapCompartment` для toggle переноса строк

Compartment — это правильный способ менять конфиг CodeMirror без потери состояния (курсор, undo-история, скролл). Без них пришлось бы пересоздавать весь EditorView, и каждое изменение настройки сбрасывало бы редактор в начало.

### Subset splitting шрифтов

Каждый шрифт у нас представлен **парой** `@font-face` (latin + cyrillic) с одинаковым `font-family` и разным `unicode-range`. Браузер сам выбирает, какой файл загружать в зависимости от кодпоинтов в тексте. Это стандартная практика fontsource — даёт оптимальный размер загрузки.

### Line-height через CSS-переменную

Раньше я задавал line-height в Tailwind config как часть fontSize utility (`['17px', { lineHeight: '1.7' }]`). С новым подходом line-height отдельно — задаётся через `--reader-line-height`, чтобы можно было менять независимо от размера. Чище для трёх independent параметров (family / size / lineHeight).
