## Что исправлено

### 1. Меню расширено

Бургер-меню было `w-64` (256px), теперь `w-72` (288px). `Ctrl+Shift+S` помещается на одной строке вместе с лейблом "Сохранить как…".

### 2. Toggle переноса строк

Корень бага: я использовал Tailwind arbitrary value `translate-x-[18px]`, и **JIT-компилятор Tailwind не всегда генерирует класс** для arbitrary translate-значений в template literals — иногда срабатывает purge или value интерпретируется как стандартный класс (`translate-x-18` = 18 × 0.25rem = **72px** вместо 18px). На скрине ручка съезжала именно потому, что translate был сильно больше планируемого.

**Решение:** переписал toggle на абсолютное позиционирование с inline-style — никаких arbitrary classes, чистая математика:

```tsx
<span
  className="absolute h-5 w-5 rounded-full bg-white shadow-soft transition-[left] duration-200"
  style={{ top: 2, left: value ? 18 : 2 }}
/>
```

Это **гарантированно** работает — никаких сюрпризов с purge или генерацией классов.

Бонус: добавил `shrink-0` на сам button, чтобы toggle не сжимался в случае, если row становится тесной (например, при длинном лейбле в другом языке).

### 3. Версия 0.1.0 → 1.0.1

Обновлено в **четырёх местах** (это важно — версия живёт во всех manifest'ах + UI):

- `package.json` — npm package version
- `src-tauri/tauri.conf.json` — версия в Tauri-сборке (попадает в installer'ы)
- `src-tauri/Cargo.toml` — версия Rust crate
- `src/components/chrome/SettingsModal.tsx` — константа `APP_VERSION` для отображения в About

Все четыре теперь синхронизированы. На будущее: при следующем bump'е надо менять во всех четырёх местах.
